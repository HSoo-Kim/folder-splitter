Windows 標準のファイル一覧（Shell `IExplorerBrowser`）を使うファイルマネージャーです。既存の `explorer.exe` を変更・置換せず、独立したアプリとして動作します。

## 主な機能

| 機能 | 説明 |
|---|---|
| **高速検索** | アドレスバーに名前やパスの一部を入力します。アプリ自身が管理する索引により、約230万パスでも通常 10 ms 前後で結果が出ます。Everything の導入もファイル内容の読み取りも不要です。[詳細](#アドレスバーがそのまま検索ボックス) |
| **最大4ペイン、ペインごとに独立したタブ** | 元・先・参考のフォルダーを一つのウィンドウに並べます。タブはペイン間でドラッグでき、端に置くと分割できます。 |
| **閉じたタブ・ペインを元に戻す** | `Ctrl+Shift+T` で直前に閉じたタブや分割を位置と比率ごと復元します。ペインごとの元に戻すボタンもあります。 |
| **その場でプレビュー** | 画像や複数ページの PDF を一覧の横で確認できます。ファイルを固定したり、別ウィンドウに分けて並べて比べられます。 |
| **比較と整理** | 片側だけにあるファイル、新しいファイル、サイズの違うファイルを探し、別のペインへコピー・移動できます。一括名前変更は新しい名前を先に確認できます。 |
| **前の作業をそのまま** | 起動時にタブと配置を復元します。作業セットを名前で保存でき、`Win+Alt+E` でどこからでも呼び出せます。 |
| **Windows 標準の操作、好みの表示** | 右クリックメニュー、ドラッグ＆ドロップ、コピーのダイアログは Windows のままです。15種類のテーマ、フォント、行間、コマンドバーの表示を選べます。 |

### AI 検索ベータ（準備中）

> **v0.8.11 および現在の安定版には含まれていません。** 準備・テスト中の機能を先行して紹介するもので、リリースまでに内容が変わる可能性があります。

探したいファイルを普段の言葉で説明して見つける会話パネルです。

- **自然言語によるファイル名検索**：アプリのローカル索引から探します。
- **必要なときだけ文書の内容を読み取り（任意）**：依頼したときに、見つかった文書の内容を読み、回答に出典ファイルを示します。
- **選択・コピーできる会話**と、見つかったファイルへの操作：開く、現在のペインで開く、新しいタブ、新しいペイン、プレビュー。
- **モデルの選択**：ローカルエンドポイント、または対応する Claude・Codex のサブスクリプションモデル。
- **個人用の指示（任意）**：回答のしかたを指定できます。

## クイックスタート

1. [folder-splitter-win-x64.zip](https://github.com/HSoo-Kim/folder-splitter/releases/latest/download/folder-splitter-win-x64.zip) をダウンロードします（Windows 11、または Windows 10 バージョン 2004 以降、x64）。
2. 展開して `FolderSplitter.exe` を実行します。インストールは不要で、.NET ランタイムも同梱しています。
3. ペインのアドレスバーに名前の断片を入力するか、サイドバーからフォルダーを選びます。

現在の実行ファイルにはコード署名がなく、Windows が発行元を確認できない旨の警告を表示する場合があります。開発とテストは Windows 11 で行っています。

## アドレスバーがそのまま検索ボックス

フルパスを覚えていなくても大丈夫です。アドレスバーに**覚えている名前の一部**を入力すると、入力と同時に一致するフォルダーとファイルが表示されます。`shared/monthly` のようにフォルダー名とファイル名の断片を `/` でつなぐと絞り込めます。

![アドレスバーに「shared/monthly」と入力すると、フォルダーとファイルの候補がすぐに表示される画面](docs/images/folder-splitter-search-en-v0.8.4.png)

- **フォルダー**を選ぶとそのフォルダーへ移動し、**ファイル**を選ぶとそのファイルがあるフォルダーを開いてファイルを選択します。
- 検索結果にはファイル一覧と同じアイコンを表示します。同期状態や文書セキュリティの鍵マークなど、他のプログラムがアイコンに付ける表示も含まれます。
- 上下キーと Enter、またはクリックで選びます。現在のフォルダー、開いているタブ、お気に入り、最近閉じたタブに近い結果が先に並び、その後によく開くフォルダー（3 回以上）の中の結果が続きます。
- 一覧は最も一致度の高い 50 件から始まります。さらにある場合は **さらに表示**（↓ で最後の行まで移動して Enter、またはクリック）で最大 200 件、もう一度で 500 件まで表示します。それ以降は名前をさらに入力して絞り込んでください。
- ローカルドライブをアプリ自身が索引化するため、Everything などの別ツールは不要です。ファイルの内容は読み取りません。

### 検索のしかた

たとえば `D:\研究\KMA500m_15分_資料共有_20261020\Raw_data_15min_rain\rn_15m_2022_08.nc` を探す場合：

| 入力 | ルール | 見つかるもの |
|---|---|---|
| `rn 2022_08` | スペースで区切った断片が**すべて名前に含まれて**いれば見つかります。 | `rn_15m_2022_08.nc` |
| `nc 15m 2022` | **順序は自由**で、名前の途中の断片でもかまいません。 | `rn_15m_2022_08.nc` |
| `.NC 2022_08` | 大文字と小文字は区別しません。 | `rn_15m_2022_08.nc` |
| `資料共有` | フォルダーも名前の断片で見つかります。 | `KMA500m_15分_資料共有_20261020` フォルダー |
| `15min_rain/rn_15m` | `/` でつなぐとパスに沿って絞り込みます。前の断片はフォルダー名の末尾、後の断片はその中の項目名の先頭です。 | `rn_15m_…` のファイル |
| `"会議 資料"` | スペースを含む名前は引用符で囲みます。 | `会議 資料.pptx` など |

スペースで区切った断片は、各ファイル・フォルダーの**自分の名前**の中だけで探します。そのため `資料共有 nc` のように親フォルダー名とファイル名の断片を混ぜると見つかりません。ファイル名の断片だけを使う（`rn nc`）か、`/` でパスをつないでください。

### 検索速度

**約 230 万件のパスで、検索は通常 10ms、95% が 31ms 以内に終わります。**（0.7.17、2026-10-23 測定）

| 検索語の種類 | 通常(p50) | 95% 境界(p95) |
|---|---:|---:|
| 名前の断片 | 9.4ms | 22.2ms |
| 大文字・小文字を変えた断片 | 9.4ms | 22.0ms |
| 部分パス（`フォルダー/名前`） | 11.5ms | 12.7ms |
| 韓国語の部分パス | 16.1ms | 16.5ms |
| 短く一致が非常に多い検索語 | 32.8ms | 95.3ms |
| 一致しない検索語 | 8.0ms | 8.1ms |
| **全体** | **9.6ms** | **31.0ms** |

C ドライブ全体（索引除外を適用、2,298,670 件のパス）で、37 個の検索語、上位 100 件、優先フォルダー 6 個の条件で、ウォームアップ 3 回の後 5 回（計 185 回）測定しました。Ryzen 9 9950X、Windows 11。初回の索引作成は約 26 秒、保存済み索引の読み込みは 0.25 秒でした。

**Everything との比較**（2026-10-21、以前のエンジン、除外なしで約 372 万件）：全体の p95 は Folder Splitter 62.1ms、Everything 連携 164.6ms でした。短く一致が非常に多い検索語は Everything の方が速い結果でした（68.8ms 対 7.1ms）。その後エンジンと索引範囲が変わり、Everything との比較は行っていません。[測定条件と全結果](docs/search-evidence/benchmark.md)

### 軽量な動作

| 項目 | 値 |
|---|---|
| アプリのメモリ（起動直後、4 分割） | 約 280MB |
| 待機中の CPU | 1% 未満 |
| 検索索引のメモリ | 約 150MB（約 230 万件のパス） |
| 新しいファイルが検索に反映されるまで | 2～3 秒 |

頻繁に変化するシステムフォルダー（Windows、`ProgramData`、`AppData` など）は索引化せず、変更をまとめて反映するため、待機中は CPU をほとんど使いません。開発者の PC での値で、ファイル数によって異なります。長時間起動しているとメモリが多少増えることがあります（この PC では数時間後に約 460MB）。0.7.14 は同じ PC で起動直後に約 1.2GB でした。

## 機能

### 分割とタブ
- **1~4分割**：上部のボタンまたは `Ctrl+1`~`Ctrl+4` で切り替えます。3分割は左右・上下の2対1配置も選べます。
- **サイズ調整**：境界線をドラッグして調整し、均等サイズのボタンで戻します。
- **ペインごとのタブ**：ペインごとに独立したタブを使えます。`+` または `Ctrl+T` で空のタブを開き、そのままアドレスを入力できます。同じフォルダーをもう一つ開くにはタブを右クリック →「タブを複製」。閉じたタブの復元にも対応します。
- **タブをドラッグして配置**：ファイル一覧の端に置くとその方向に分割し、中央に置くとそのペインへ移動します。空のペインにも置けます。
- **タブの幅とタブ一覧**：タブはフォルダー名の長さに合わせて伸び縮みし、タブが 1 つだけなら長い名前もより長く表示します。タブが増えると均等に縮み、それでも収まらない場合は `+` の横の `▾` ボタンからすべてのタブを選べます。
- **空のペイン**：新しく分割したペインは空です。アドレスを入力するか、左側のショートカットからフォルダーを開きます。
- **使用中のペインを維持**：1 ペインに切り替えるとアクティブなペインを残し、タブがなければ表示中でタブのあるペインを優先します。非表示になったペインのタブも保持されます。
- **ペイン間の移動**：`F6` で次のペイン、`Shift+F6` で前のペインへ移動し、端では反対側に戻ります。`Alt+1`～`Alt+4` でその番号のペインへ直接移動します。開いていないペインの場合はステータス行でお知らせします。
- **分割を閉じる・復元する**：`Ctrl+W` でタブを閉じ、タブがない状態でもう一度押すとその分割を閉じます。最後の 1 ペインは残ります。`Ctrl+Shift+T` は閉じた順序の逆順に復元し、まず空のペインを元の位置・比率で戻し、もう一度押すとタブを戻します。新しい配置を選ぶと以前の分割の復元履歴は消去されます。
- **読みやすいショートカットヘルプ**：`?` または `F1` で、カテゴリ移動とキー・説明の 2 列表示を備えたヘルプを開きます。テーマとフォント設定に従い、狭いウィンドウでは折り返します。
- **2 種類の閉じた履歴**：各ペインのフィルター欄の横にある丸い元に戻す・やり直すボタンは、そのペインで閉じたタブだけを戻します。右上の `設定` の左にある一組は、すべてのペインで閉じたタブと分割を扱い、`Ctrl+Shift+T` と同じです。どちらから戻しても同じ項目が二度戻ることはありません。ボタンにポインターを置くと範囲とショートカットが表示されます。

### 移動と検索
- **アドレスバー検索**：名前の一部を入力するだけで、すべてのローカルドライブからすぐに見つけます。[詳しく](#アドレスバーがそのまま検索ボックス)
- **移動**：パス入力と自動補完、戻る・進む・親フォルダー、マウスのサイドボタンに対応します。
- **パスボタン**：アドレスバーに各フォルダーがボタンで表示されます（`C: › Users › …`）。クリックでそのフォルダーへ、`›` でサブフォルダーの一覧を開きます。空いている所をクリックするか `Ctrl+L` で、これまでどおりパス入力や検索ができます。
- **最近の場所**：戻る・進むボタンを右クリックすると、このタブで訪れたフォルダーの一覧が出ます。
- **フォルダーの参照**：アドレスバー横のフォルダーアイコンで選択画面を開きます。

### サイドバー
- **クイックアクセス**：ホーム、デスクトップ、ダウンロード、ドキュメント、最近使った項目、PC、ごみ箱。クリックするとアクティブなペイン（上部の青い線）で開きます。「最近使った項目」はエクスプローラーと同じく、最近開いたファイルとフォルダーを新しい順に表示します。ショートカットではなく実際のファイルなので、ドラッグ・コピー・パスのコピーでは元のファイルを渡し、削除や名前の変更も元のファイルに適用されます。ローカルドライブから削除されたファイルは表示しません。
- **お気に入り**：`Ctrl+D` で追加し、右クリックで外します。初回起動時にエクスプローラーの固定フォルダーを取り込み、管理メニューで再取り込み・すべて削除・復元ができます。エクスプローラー側は変更しません。
- **フォルダーツリー**：アクティブなペインの場所に追従します。クリックで現在のペイン、中クリック・Ctrl+クリックで新しいタブ、右クリックで新しいペインやエクスプローラーで開きます。`Ctrl+Shift+E` で折りたたみます。
- **サイズ**：境界線でサイドバーの幅とお気に入り・ツリーの高さを調整し、サイドバーボタンで隠せます。

### ファイル操作
- **Windows 標準の操作**：右クリックメニュー、コピー・切り取り・貼り付け、名前の変更、削除、ペイン間のドラッグ＆ドロップは Windows がそのまま処理します。
- **コマンドバー**：各ファイル一覧の上に、エクスプローラーと同じく「新しいフォルダー」「切り取り」「コピー」「貼り付け」「名前の変更」「削除」（ごみ箱へ、`Ctrl+Z` で元に戻せます）があります。ボタンにポインターを置くと名前とショートカットが表示されます。
- **並べ替え・表示メニュー**：名前・更新日時・種類・サイズ順、昇順・降順で並べ替え、種類や日付でグループ化できます。「表示」では特大アイコンから小アイコン、一覧、詳細、並べて表示、コンテンツを切り替え、エクスプローラーの「隠しファイルを表示」「ファイル名拡張子を表示」（Windows 全体の設定なのでエクスプローラーも同じになります）と詳細ウィンドウを切り替えます。
- **クイックフィルター**：コマンドバー右側の欄に入力すると、今のフォルダーでその文字を含む名前だけが残ります（複数の語はすべて含むものだけ）。`Esc` で消え、タブが別のフォルダーを開くと自動で解除されます。
- **複数の名前を一括変更**：2 つ以上の項目を選んで「名前の変更」を押します。文字の検索と置換（正規表現も可）、`{n}` による連番を指定し、適用前にすべての新しい名前を確認できます。拡張子はそのまま、名前の重複は止め、エクスプローラーで `Ctrl+Z` を 1 回押せばすべて元に戻ります。
- **詳細ウィンドウ**：「表示」→「詳細ウィンドウ」をオンにすると、プレビューの下にエクスプローラーと同じく選択項目のプロパティが表示されます。種類・場所・サイズ・日付に加え、写真は解像度、動画・音楽は長さ、文書は作成者などです。
- **2 つのペインを比較**：コマンドバーの `⇄` を押すと、このフォルダーと別のペインのフォルダーを比べ、片側にしかない項目、新しいファイル、サイズの違うファイルを表示します。ボタン 1 つでそれらの項目を各ペインで選択し、そのままコピーできます。
- **表示**：ペインのオプションで詳細・一覧・アイコンを選ぶか、同じフォルダーを Windows エクスプローラーで開きます。グループ化・並べ替え・表示形式はエクスプローラーと同じくフォルダーごとに記憶します。
- **項目数と選択情報**：各ペインの下部に項目数を示し、選択すると数とファイルサイズの合計も表示します（例：`3 個選択 · 1.2 GB`）。
- **プレビュー**：「プレビュー」ボタンまたは `Alt+P` でオンにしてファイルをクリックします。表示状態と幅を記憶します。
- **別のペインへコピー・移動**：`Ctrl+Alt+C`（コピー）、`Ctrl+Alt+X`（移動）またはペインのオプション（⚙）で、選択した項目を別のペイン（直前に使ったペイン）のフォルダーへ送ります。進行状況、名前の競合、元に戻す（`Ctrl+Z`）はエクスプローラーと同じ Windows のコピー画面が処理します。
- **現在のフォルダーを別のペインで開く**：`Ctrl+Alt+O` またはペインのオプション（⚙）で、現在のフォルダーを別のペインで開き、そのペインへ移動します。そのフォルダーを表示中のタブがあればそれを選択し、選択中のタブが空ならそのタブを使い、そうでなければ新しいタブを追加します。ペインが 1 つだけのときは、先に 2～4 分割を選ぶようステータス行で案内します。
- **固定と新しいウィンドウ**：プレビュー上部の「固定」を押すと、他のファイルを選んでもそのプレビューが残ります。「新しいウィンドウ」でそのファイルだけの別ウィンドウを開き、複数並べて比較できます（最大 8 個、PDF のホイール移動も可能）。
- **パスのコピー、ターミナル**：`Ctrl+Shift+C` で選択項目のパスをエクスプローラーと同じく引用符付きでコピーします（選択がなければ現在のフォルダー）。ペインのオプションの「ここでターミナルを開く」で、そのフォルダーで Windows ターミナル（なければ PowerShell）を開きます。
  - **複数ページの PDF**：PDF アプリの追加は不要です。プレビュー上でホイールを下へ回すと次ページ、上へ回すと前ページに移動します。下部のページ番号と前後のボタンも使えます。
  - **別ウィンドウ**：ファイル名の見出しをドラッグするか「別ウィンドウ」を押すと切り離せます。メインウィンドウの右側へドラッグするか「元に戻す」を押すと戻り、表示中の PDF ページも維持されます。
  - **その他の形式**：写真は Windows のサムネイル、Office・テキストなどはインストール済みのエクスプローラー用プレビューハンドラーを使います。文書上のホイールはファイル一覧ではなくプレビューに渡され、スクロールやページ移動の対応範囲はハンドラーによって異なります。

### 外観と設定
- **上部ツールバー**：「サイドバー」の左にあるピンで全体のツールバーを固定します。固定を解除すると隠れ、ウィンドウのタイトルバーの空いている場所にポインターを約 0.35 秒置くと作業領域の上に表示されます。ピンをもう一度押すか `Ctrl+Shift+F11` で切り替え、設定は保存されます。
- **カラーテーマ**：右上のメニューから 15 種類を選べます。標準の「ライト」「ダーク」、目にやさしい「ベージュ」「ライトグリーン」「スカイブルー」「パステルブルー」「ソフトダーク」、そして有名なデザインパレット（Solarized、Everforest、Gruvbox、Rosé Pine、Catppuccin、Nord）をもとに上部バー・サイドバー・ファイル一覧・並べ替え列をそれぞれ別の色にした組み合わせ 8 種類です。
  ![Folder Splitter の 15 種類のカラーテーマのパレット](docs/images/folder-splitter-themes-v0.7.29.png)
- **フォントと文字サイズ**：「設定」→「フォントと文字サイズ」で、インストール済みのフォント（Malgun Gothic、Pretendard、NanumGothic など）と文字の小・標準・大を選ぶと、ファイル一覧も一緒に変わります。
- **アクティブなペインの枠線**：現在のペインを太い枠線で示します。「表示」→「アクティブなペインの色」でテーマの既定色・青・緑・アンバーを選べます。すべてのペインに共通で適用され、再起動後も保持されます。
- **一覧の見た目**：各ペインの `表示` メニューは、このペインのみ、すべてのペイン、Windows 全体の設定に分かれています。すべてのペイン共通で、コマンドバーを隠す（フィルターは `Ctrl+F`、その他のコマンドはペインのオプションにあります）、縦の区切り線と並べ替え列の強調表示のオン・オフ（どちらも既定はオフ）、行間の `コンパクト`・`標準`（既定）を選べます。`標準` は行の間隔だけを広げ、アイコンと文字の大きさは変わりません。
- **フォルダーのファイル合計**：ステータス行に「このフォルダーのファイル 18.4 MB」のように、今のフォルダーに直接あるファイルの合計サイズが表示されます。サブフォルダーまでは調べず、フォルダーを 1 回読むだけなので PC に負担がかかりません。ネットワークフォルダーはスキップします。
- **言語**：한국어、English、简体中文、日本語。
- **作業状態の復元**：タブ、お気に入り、分割比率、ウィンドウサイズ、テーマ、サイドバーの状態を次回の起動に引き継ぎます。
- **作業セット**：上部の「作業セット」で、今の分割とタブに名前を付けて保存し、後で呼び出せます（最大 20 個）。プロジェクトごとに切り替えるときに便利です。
- **バージョンと更新**：左下に現在のバージョンと、新しいバージョンがある場合はリンクを表示します。アプリが見えているときは右下に更新通知が現れ、「閉じる」を押すまで表示されます。閉じた後もリンクは残ります。自動インストールがオンで実行ファイルに書き込める場合は「更新」でインストールして再起動し、それ以外はリリースページを開きます。クリックするまではインストールしません。起動時、実行中は 1 時間ごと、前回の確認から 15 分以上たってウィンドウを再表示したときに確認します。
- **メモリの整理**：ファイル一覧に使う Windows エクスプローラーの部品は、フォルダーを移動するたびに少しずつメモリを溜め、アプリの終了時にしか返しません。そのためメモリが基準（既定 100 MB）を超えて増えると、ウィンドウが非表示または最小化されているときにタブ・分割・設定を保存して静かに再起動します。「設定」→「メモリの整理」で 100・200・300・500 MB またはオフを選ぶか、「今すぐメモリを整理」ですぐ再起動できます。

ファイル一覧は Windows 標準の一覧なので、列の並べ替えと右クリックメニューは Windows Shell が処理します。Windows 11 エクスプローラーのコマンドバーやタブ UI 自体を埋め込むものではありません。

## すばやく呼び出す

| 状況 | 動作 |
|---|---|
| `Win+Alt+E` | どのアプリからでもウィンドウを前面に表示し、もう一度押すと通知領域に隠します。 |
| ウィンドウを閉じる（X） | 終了せず、通知領域（隠れているインジケーター）に残ります。初回のみ案内が表示されます。 |
| `Win+E` | 「設定」でオンにした場合だけ Folder Splitter が開きます。既定ではエクスプローラーが開きます。アプリが前面にあるときにもう一度押すと、Win+Alt+E と同じく隠します。 |
| もう一度起動 | 新しいウィンドウではなく既存のウィンドウを呼び出します。 |

- **完全に終了**：通知領域のアイコンを右クリック →「終了」。
- **「設定」で変更できるもの**：Win+Alt+E、閉じても通知領域に残す、Win+E の置き換え、新しいバージョンの確認、更新の自動インストール。
- 通知領域のオプションをオフにすると、X で終了し、Win+Alt+E の再入力は最小化になります。
- Win+E の設定は現在のユーザーのレジストリ（HKCU）に1項目だけを作成・削除し、管理者権限は不要です。

## Q-Dir との比較

2つのアプリはファイルの探し方が異なります。

| | Q-Dir | Folder Splitter |
|---|---|---|
| 検索する場所 | 別の検索ボックス（Windows エクスプローラーの検索、`F3`・`Ctrl+F`） | アドレスバーに直接入力 |
| 検索範囲 | 現在のフォルダーとその下位 | すべてのローカルドライブ |
| 速度 | Windows Search の索引状況によって異なり、索引のない場所は遅いことがある | 独自のファイル名索引で入力と同時に結果を表示（初回索引は約50秒） |
| 外部ツール | Everything との標準連携なし | 不要 |

> **基準**：2026-10-22 時点で Q-Dir 12.81（2026-10-18 公開）を対象に、公式 FAQ（検索の項目は 2024-04-29 更新）と公式ヘルプを参照してまとめました。実際にインストールして確認してはいません。公式文書では独自の検索機能を開発中としているため、今後のバージョンで変わる可能性があります。誤りがあれば Issue でお知らせください。
>
> 出典：[Q-Dir 公式サイト](https://www.softwareok.com/?seite=Freeware/Q-Dir) · [検索 FAQ](https://www.softwareok.com/?seite=faq-Q-DIR&faq=37) · [ヘルプ](http://www.q-dir.com/?en-us-q-q-dir-file-explorer-help.-for-windows-10-11-12-7)

## 使い方

1. 上部で分割数を選びます。
2. 各ペインのアドレスバーにパスまたは名前の一部を入力して Enter を押します。
3. `+` でタブを追加し、タブを好きなペインへドラッグします。
4. ファイル一覧では Windows と同じショートカットを使います。

## データと互換性

- 新しいバージョンの確認：起動時、実行中は 1 時間ごと、前回の確認から 15 分以上たってウィンドウを再表示したときに、GitHub（`api.github.com`）から最新リリースの情報だけを読み取ります。ファイルやユーザーの情報は送信しません。「設定」→「新しいバージョンを確認」でオフにできます。
- 更新：「更新」をクリックしたときだけ GitHub のリリースから ZIP を取得し、GitHub が示す SHA256 と一致するか確認してから実行ファイルを置き換えます。以前のファイルは次回起動時に削除します。確認に失敗した場合は何も変更しません。実行ファイルが書き込みできない場所にある場合や、「設定」→「「更新」をクリックしたら自動でインストール」をオフにした場合はリリースページを開きます。これ以外のネットワーク接続はありません。
- 設定ファイル：`%LOCALAPPDATA%\QuadExplorer\session.json`
- 旧 QuadExplorer のタブとお気に入りを引き継ぐため、設定の保存先は変更していません。
- 同じ設定ファイルを使うアプリは同時に1つだけ実行してください。
- 1ペインあたり最大32タブ、お気に入りは最大100件です。
- よく開くフォルダー：検索結果の順序を決めるため、フォルダーを開いた回数を数えます。保存するのはフォルダーのパスと回数だけで（最大 100 件、設定ファイルに保存、回数は時間とともに減ります）、ファイル名や検索語は保存しません。`設定` → `よく開くフォルダーの履歴を消去` で消せます。以前のバージョンはこの項目を無視します。
- 接続が切れたドライブや存在しないフォルダーではエラーを表示します。アドレスバーから別のフォルダーを選択できます。
- ファイルの削除・上書き・競合処理は Windows Shell に委ねます。アプリ独自の再帰削除は行いません。
- OneDrive/Dropbox の状態表示、外部の Shell 拡張、ネットワーク共有は、各サービスのインストール状態と権限に依存します。
- 使用可能なローカル固定ドライブのファイル・フォルダー名とパスをバックグラウンドで索引化します。内容は読みません。初回は索引の準備状態を表示し、次回からは保存済みの索引を使いながら変更を照合します。
- 索引しないもの：Windows フォルダー、`ProgramData`、各ユーザーの `AppData`、ごみ箱、`System Volume Information` の中身。ほとんどがプログラム内部のファイルで常に変化するため、除外するとメモリと CPU の使用量が大きく減ります。フォルダー自体は名前で検索でき、パスを入力すればそのまま開けます。
- 新しく作成・変更されたファイルは、変化が落ち着いてから約 2～3 秒で（変化が続く間も最大約 10 秒ごとに）検索に反映されます。
- キャッシュ：`%LOCALAPPDATA%\FolderSplitter\Search\paths.v1.index`。`--session` 指定時は設定ファイルの隣の `.search.index` を使います。アクセスできないパス、ジャンクション・シンボリックリンクの内部は対象外です。ネットワーク・リムーバブルドライブは直接パスで移動できます。
- 既定のエクスプローラーの置換、既存のタブの取り込みには対応していません。[測定結果と制限](docs/search-evidence/benchmark.md)を参照してください。

別の作業セッションやテストには設定ファイルを指定できます。

```powershell
.\FolderSplitter.exe --session C:\Work\folder-session.json C:\Projects D:\Research
```

追加のフォルダー引数はアクティブなペインの新しいタブで開きます。

## ソースからビルド

必要環境：Windows 10（2004 以降）または 11 x64、.NET 10 SDK。

```powershell
.\build.ps1                 # Release ビルドと設定の回帰テスト
.\build.ps1 -UiTests        # 実際のネイティブウィンドウによる統合テストも実行
.\build.ps1 -Publish        # ランタイム同梱の実行ファイルと ZIP を生成
```

UI 統合テストは `tools/PrivateDesktopQa` が作成する別の非公開 Windows デスクトップで実行するため、使用中の画面にウィンドウを開いたり、マウスやキーボードを操作したりしません。ログイン済みの Windows セッションが必要です。一時フォルダーのみを使用し、移動完了イベントを待ちます。固定時間の待機には依存しません。

出力：

```text
artifacts/FolderSplitter/FolderSplitter.exe
artifacts/folder-splitter-win-x64.zip
```

公開用のビルドが成功した後、以前のバージョンの生成済み実行ファイルを整理し、ローカルには最新版のみを残します。ソース、設定、利用者のファイルは削除しません。

## 構成

```text
src/FolderSplitter/
  MainForm.cs           ウィンドウ、分割、クイックアクセス、ショートカット
  ExplorerPane.cs       ペインごとのタブとアドレスバー
  ShellViewHost.cs      ネイティブ Shell ビューのライフサイクル
  ShellInterop.cs       Windows SDK COM/PInvoke 宣言
  SessionState.cs       設定の検証とアトミック保存
  Theme.cs              カラーテーマと角丸の共通コントロール
  FolderTree.cs         左側のフォルダーツリー
  ShellIconCache.cs     クイックアクセスの Windows アイコン
  Assets/               アイコンの PNG 原本と複数解像度の ICO
tests/
  QuadExplorer.Tests/   設定モデルの回帰テスト
  ExplorerFavorites.Tests/ お気に入り取り込みテスト
  QuadExplorer.UiTests/ 実際の Shell ビューによる統合テスト
tools/
  PrivateDesktopQa/     非公開デスクトップ UI テストランチャー
```

アプリのコードは外部の NuGet パッケージに依存しません（UI テストのみ Lib.Harmony を使用）。Windows Shell と .NET Windows Forms を使用します。

アイコンの原本を置き換えた場合は、次のコマンドで Windows 用 ICO を再生成してください。

```powershell
.\tools\Build-Icon.ps1 -SourcePng .\src\FolderSplitter\Assets\app.png
```
