# Folder Splitter 0.4.0

- 빠른 접근 오른쪽 경계선을 좌우로 끌어 폭을 조절합니다. `Sidebar`로 완전히 숨겼다가 다시 열 수 있으며 폭과 표시 상태를 저장합니다.
- 새 분할 영역은 빈 공간으로 둡니다. 주소를 입력하거나 바로가기를 선택하면 폴더가 열립니다. 마지막 탭을 닫아도 같은 폴더를 자동으로 열지 않습니다.
- 최초 실행 시 Windows 파일 탐색기의 고정 폴더와 이전 Links 폴더의 바로가기를 기본 즐겨찾기로 가져옵니다. 기존 즐겨찾기도 유지합니다.
- `Manage...`에서 탐색기 즐겨찾기 다시 가져오기, 전체 제거, 선택 복원을 지원합니다. 복원 목록에는 제거한 즐겨찾기와 휴지통·내 PC 등 기본 위치가 있습니다.
- 앱에서 즐겨찾기를 제거해도 Windows 파일 탐색기의 고정 목록은 변경하지 않습니다.
- 상단 도구 모음과 상태줄을 글자 높이에 맞춰 배치해 배율에 따른 잘림을 수정했습니다.

`folder-splitter-win-x64.zip`을 풀고 `FolderSplitter.exe`를 실행합니다.
Windows 11 x64용, .NET 런타임 포함, 코드 서명 없음.
기존 세션과 탭은 보존합니다.
