# Folder Splitter 0.5.2

## 새 기능

- 창 왼쪽 아래에 현재 실행 버전을 표시합니다. 사이드바를 숨겨도 보이며, 실행 파일의 버전 정보를 자동으로 읽습니다.
- 주소창 옆 폴더 아이콘으로 Windows 폴더 선택 창을 열 수 있습니다.
- 화살표·폴더 선택·옵션·주요 버튼에 마우스를 올리면 기능 설명이 표시됩니다.
- 한국어 / English / 简体中文 / 日本語를 실행 중에 전환하고 다음 실행에도 유지합니다.
- 언어 선택은 상단 탭 닫기 바로 왼쪽에 있습니다. 한국어 분할 버튼은 `1 분할 / 2 분할 / 3 분할 / 4 분할`로 표시합니다.
- 일본어 README를 추가하고 배포 ZIP에 4개 언어 문서를 포함했습니다.

## 수정

즐겨찾기나 빠른 접근 항목을 선택한 상태에서 언어를 바꿀 때 발생하던 목록 변경 예외를 수정했습니다.
실제 드롭다운 입력으로 오류를 재현한 뒤, 같은 조건으로 모든 언어 전환과 선택 유지 검사를 통과했습니다.

## 실행

`folder-splitter-win-x64.zip`을 풀고 `FolderSplitter.exe`를 실행합니다.
Windows 11 x64용이며 .NET 런타임을 포함합니다. 코드 서명은 없습니다.
기존 `%LOCALAPPDATA%\QuadExplorer\session.json`의 탭과 설정은 유지합니다.
Windows 기본 파일 목록과 폴더 선택 창의 언어는 운영체제 설정을 따릅니다.

## 검증

설정·분할 모델 31개, 네이티브 UI 검사 125개와 탐색기 즐겨찾기 가져오기 검사를 통과했습니다.
버전 표시, 4개 언어 전환, 탭·경로·이동 이력 유지, 최소 창 크기 배치와 목록 선택 복원을 검사했습니다.
