# Folder Splitter 0.3.0

## 새 기능

- 탭을 파일 목록 가장자리로 드래그하면 새 영역으로 분할합니다.
- 탭을 영역 가운데에 놓으면 해당 영역으로 이동합니다.
- 1/2/3/4분할을 지원하며, 3분할 메뉴에서 좌우·상하 2:1 배치를 선택할 수 있습니다.
- 탭 우클릭의 `Split tab` 메뉴로도 분할할 수 있습니다.
- 마지막 탭을 다른 영역으로 옮기면 빈 영역을 접습니다.
- 분할 트리, 영역별 탭, 비율과 활성 영역을 저장하고 복원합니다.
- 즐겨찾기 제목을 클릭하면 목록만 숨기거나 다시 표시합니다. 항목과 접힌 상태는 저장됩니다.

## 실행

`folder-splitter-win-x64.zip`을 풀고 `FolderSplitter.exe`를 실행합니다.
Windows 11 x64용이며 .NET 런타임을 포함합니다. 코드 서명은 없습니다.

기존 `%LOCALAPPDATA%\QuadExplorer\session.json` 설정은 계속 사용합니다.

## 검증

설정·분할 모델 27개와 네이티브 UI 검사 36개가 통과했습니다.
실제 마우스로 탭을 오른쪽 가장자리에 끌어 분할하는 동작과 즐겨찾기 목록 숨김도 확인했습니다.

한국어·영어·중국어 간체 사용 문서를 저장소와 ZIP에 제공합니다.
